# Rust Port of the clockify CLI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Go `clockify` CLI with a Rust binary that has the same subcommands, flags, output and config sources, fixing the issues the spec lists.

**Architecture:** A single crate at the repo root, with one module per former Go package (`src/{timeutil,clockify,validator,summary,config,trello}.rs`). `src/main.rs` holds the clap CLI, log-argument parsing, entry time math and the `log`/`summary` commands. HTTP is blocking (ureq) and there is no async runtime. Tests live in inline `#[cfg(test)] mod tests`, and HTTP tests run against mockito.

**Tech Stack:** Rust 1.95 (edition 2024), clap 4.6 (derive), ureq 3.4 (json feature), serde 1, serde_json 1, toml 1.1, chrono 0.4.45, anyhow 1; mockito 1.7 (dev).

**Spec:** `/Users/loithai/Projects/ai-tools/clockify-agent/docs/superpowers/specs/2026-10-13-rust-port-design.md`

## Global Constraints

- Binary name `clockify`, package `clockify-agent`, edition 2024, `Cargo.toml` at the repo root.
- Runtime errors print `Error: {e:#}` to stderr and exit 1. clap usage errors exit 2.
- Every message the Go code printed keeps its exact text unless the spec's Fixes section changes it. Error texts quoted in this plan are the Go texts.
- All times the user types are VNT, `FixedOffset` +07:00. Times sent to Clockify or printed in dry-run are UTC RFC 3339 with `Z`: `to_rfc3339_opts(SecondsFormat::Secs, true)`.
- Durations are `i64` seconds. Durations from `parse_duration` are at most `i32::MAX`.
- No slicing of user text inside a UTF-8 character. Parsers check `is_ascii()` before byte indexing, and cuts count `chars()`.
- Clockify and Trello JSON fields may be `null`. Every `String`/`Vec` response field uses `#[serde(default, deserialize_with = "null_default")]`.
- No new dependencies beyond the Tech Stack line.
- Commit messages: Conventional Commits, a few lines, no AI attribution lines.
- Do not edit the Go code (`main.go`, `internal/`) before Task 10. The parity check in Task 9 builds it.

## Review Focus

1. **Clockify sends `null`** for `taskId`, `projectId`, `description` and a running timer's `end`. Decoding must yield empty strings, not `failed to decode response`. Pinned in Task 2, `list_entries_for_user_sends_day_bounds_and_page_size`.
2. **Vietnamese text** in descriptions and stray non-ASCII in time arguments must never panic. Pinned in Task 1 (`2éh`, `é:00`, `2026-é-05`) and Task 7 (`entry_name_cuts_descriptions_by_character`).
3. **Absurd numbers** (`99999999999h`, `99999999999999999999:00`) must return an error, never overflow or panic in chrono. Pinned in Task 1, `parse_duration_invalid`.
4. **A running timer among today's entries** must not break the overlap or 14h checks. Pinned in Task 3, `daily_total_skips_running_timer` and `overlap_skips_running_timer`.
5. **Clockify unreachable or returning 4xx/5xx** must produce `failed to send request` / `API error: status N`, not a panic. Pinned in Task 2, `create_entry_api_error` and `unreachable_server_is_a_send_error`.

```rust
//! Duration, time-of-day and date parsing for the log command, and the H:MM:SS formatter.

use anyhow::{Context, Result, anyhow, bail};
use chrono::NaiveDate;

/// Parses a duration into seconds: "H:MM:SS" or "H:MM" (hours below 24), or
/// "1h30m" / "1h" / "30m" / "45s" style.
pub fn parse_duration(s: &str) -> Result<i64> {
    if s.contains('h') || s.contains('m') {
        return parse_human_duration(s);
    }
    let parts: Vec<&str> = s.split(':').collect();
    let (hours, minutes, seconds) = match parts.as_slice() {
        [h, m, sec] => (num(h, "hours")?, num(m, "minutes")?, num(sec, "seconds")?),
        [h, m] => (num(h, "hours")?, num(m, "minutes")?, 0),
        _ => bail!("invalid duration format"),
    };
    if hours >= 24 || minutes >= 60 || seconds >= 60 {
        bail!("invalid time component");
    }
    Ok(hours * 3600 + minutes * 60 + seconds)
}

/// Parses 24-hour "HH:MM" into seconds from midnight ("09:00" is 32400).
pub fn parse_time_hhmm(s: &str) -> Result<i64> {
    if !s.is_ascii() || s.len() != 5 || s.as_bytes()[2] != b':' {
        bail!("invalid time format");
    }
    let (hours, minutes) = (num(&s[..2], "hours")?, num(&s[3..], "minutes")?);
    if hours >= 24 || minutes >= 60 {
        bail!("invalid time component");
    }
    Ok(hours * 3600 + minutes * 60)
}

/// Parses "YYYY-MM-DD". A date the calendar lacks, such as 2026-02-31, is an error.
pub fn parse_date(s: &str) -> Result<NaiveDate> {
    if !s.is_ascii() || s.len() != 10 || s.as_bytes()[4] != b'-' || s.as_bytes()[7] != b'-' {
        bail!("invalid date format");
    }
    let year = num(&s[..4], "year")?;
    let month = num(&s[5..7], "month")?;
    let day = num(&s[8..], "day")?;
    NaiveDate::from_ymd_opt(year as i32, month as u32, day as u32).context("invalid date component")
}

/// Parses "4h ago" / "30m ago" / "1h30m ago" into seconds in the past.
pub fn parse_relative_time(s: &str) -> Result<i64> {
    match s.trim().strip_suffix(" ago") {
        Some(d) => parse_duration(d),
        None => bail!("invalid relative time format"),
    }
}

/// Formats seconds as "H:MM:SS", or "0:MM" / "0:MM:SS" under an hour. Negative is "0:00".
pub fn format_duration(seconds: i64) -> String {
    if seconds < 0 {
        return "0:00".into();
    }
    let (h, m, s) = (seconds / 3600, seconds % 3600 / 60, seconds % 60);
    if h > 0 {
        format!("{h}:{m:02}:{s:02}")
    } else if s > 0 {
        format!("0:{m:02}:{s:02}")
    } else {
        format!("0:{m:02}")
    }
}

/// Parses "1h30m", "1h", "30m", "45s". The total is capped at i32::MAX seconds so
/// later chrono arithmetic on it can't overflow.
fn parse_human_duration(s: &str) -> Result<i64> {
    let mut total: i64 = 0;
    let mut rest = s;
    while !rest.is_empty() {
        let idx = rest.find(|c: char| !c.is_ascii_digit()).unwrap_or(0);
        if idx == 0 {
            bail!("invalid duration format");
        }
        let val: i64 = rest[..idx].parse().map_err(|_| anyhow!("invalid duration number"))?;
        let unit = rest[idx..].chars().next().unwrap_or_default();
        rest = &rest[idx + unit.len_utf8()..];
        let scale = match unit {
            'h' => 3600,
            'm' => 60,
            's' => 1,
            _ => bail!("unknown duration unit '{unit}'"),
        };
        total = val
            .checked_mul(scale)
            .and_then(|v| v.checked_add(total))
            .filter(|t| *t <= i64::from(i32::MAX))
            .context("invalid duration number")?;
    }
    if total == 0 {
        bail!("empty duration");
    }
    Ok(total)
}

/// Reads an unsigned decimal field (ASCII digits only; Go's Sscanf read "5x" as 5).
/// `what` names the field in the error: "invalid hours".
fn num(s: &str, what: &str) -> Result<i64> {
    if s.is_empty() || !s.bytes().all(|b| b.is_ascii_digit()) {
        bail!("invalid {what}");
    }
    s.parse().map_err(|_| anyhow!("invalid {what}"))
}
```

```rust
/// as `taskId`, and for a running timer's `end`.
pub fn null_default<'de, D, T>(d: D) -> Result<T, D::Error>
where
    D: Deserializer<'de>,
    T: Default + Deserialize<'de>,
{
    Ok(Option::<T>::deserialize(d)?.unwrap_or_default())
}

    }

        self.post(&format!("/workspaces/{}/time-entries", self.workspace_id), entry)
    }

    /// The user's entries from `start` 00:00:00Z to `end` 23:59:59Z (dates as YYYY-MM-DD).
    pub fn list_entries_for_user(&self, user_id: &str, start: &str, end: &str) -> Result<Vec<TimeEntry>> {
        // shortcut: one page of 1000 entries (the API default is 50); page through if a range ever holds more
        self.get(&format!(
            "/workspaces/{}/user/{user_id}/time-entries?start={start}T00:00:00Z&end={end}T23:59:59Z&page-size=1000",
            self.workspace_id
        ))
    }

    /// The endpoint needs special permissions and may return 403.
    pub fn get_detailed_report(&self, start: &str, end: &str) -> Result<Vec<TimeEntry>> {
        let body = json!({
            "dateRangeStart": start,
            "dateRangeEnd": end,
            "detailedFilter": {"groups": ["PROJECT"]},
            "users": {"contains": "ALL"},
            "projects": {"contains": "ALL"},
        });
        let report: DetailedReport =
            self.post(&format!("/report/workspaces/{}/reports/detailed", self.workspace_id), &body)?;
        Ok(report.timeentries)
    }

    /// when `user_id` is set, the detailed report otherwise.
    pub fn entries_between(&self, user_id: &str, start: &str, end: &str) -> Result<Vec<TimeEntry>> {
        if user_id.is_empty() {
            self.get_detailed_report(&format!("{start}T00:00:00Z"), &format!("{end}T23:59:59Z"))
        } else {
            self.list_entries_for_user(user_id, start, end)
        }
    }

    pub fn list_projects(&self) -> Result<Vec<Project>> {
        self.get(&format!("/workspaces/{}/projects", self.workspace_id))
    }

    pub fn list_tasks(&self, project_id: &str) -> Result<Vec<Task>> {

        self.post(

        decode(self.agent.get(format!("{}{path}", self.base_url)).header("X-Api-Key", &self.api_key).call())
    }

        decode(
            self.agent
                .post(format!("{}{path}", self.base_url))
                .header("X-Api-Key", &self.api_key)
                .send_json(body),
        )
    }
}

fn decode<T: DeserializeOwned>(resp: Result<ureq::http::Response<ureq::Body>, ureq::Error>) -> Result<T> {
    let mut resp = resp.context("failed to send request")?;
    let status = resp.status().as_u16();
    if status >= 400 {
        bail!("API error: status {status}");
    }
    resp.body_mut().read_json().context("failed to decode response")
}
```

```rust
//! Checks run before creating an entry: the 14h daily cap and overlap with existing entries.

use chrono::{DateTime, Utc};

use crate::clockify::TimeEntry;

pub const MAX_DAILY_SECONDS: i64 = 14 * 3600;

/// Total seconds of the entries that start on `date`'s UTC calendar day. Entries
/// without a parseable start and end (a running timer) are skipped.
pub fn daily_total(date: DateTime<Utc>, entries: &[TimeEntry]) -> i64 {
    entries
        .iter()
        .filter_map(TimeEntry::interval)
        .filter(|(start, _)| start.date_naive() == date.date_naive())
        .map(|(start, end)| (end - start).num_seconds())
        .sum()
}

/// True when existing plus new seconds go over 14h; exactly 14h is allowed.
pub fn exceeds_cap(existing_seconds: i64, new_seconds: i64) -> bool {
    existing_seconds + new_seconds > MAX_DAILY_SECONDS
}

/// The first entry that overlaps [start, end]. Entries that only touch at an endpoint
/// don't overlap; entries without a parseable start and end are skipped.
pub fn has_overlap<'a>(start: DateTime<Utc>, end: DateTime<Utc>, entries: &'a [TimeEntry]) -> Option<&'a TimeEntry> {
    entries
        .iter()
        .find(|e| e.interval().is_some_and(|(s, en)| start < en && end > s))
}
```

```rust
use std::collections::{BTreeMap, HashMap};

use anyhow::{Result, bail};
use chrono::{Datelike, Local, NaiveDate, TimeDelta};

#[derive(Debug, PartialEq)]
pub struct ProjectTotal {
    pub name: String,
    pub duration: i64,
}

#[derive(Debug, PartialEq)]
pub struct TaskTotal {
    pub name: String,
    pub duration: i64,
}

#[derive(Debug, PartialEq)]

    pub name: String,
    pub duration: i64,
    pub tasks: Vec<TaskTotal>,

const PRESETS: &str = "today, yesterday, this-week, last-week, this-month, last-month";

/// Turns a preset, or explicit from/to dates, into start and end dates (YYYY-MM-DD)
/// and a label. A non-empty preset wins over from/to.
pub fn resolve_date_range(preset: &str, from: &str, to: &str) -> Result<(String, String, String)> {
    resolve_date_range_on(preset, from, to, Local::now().date_naive())
}

fn resolve_date_range_on(preset: &str, from: &str, to: &str, today: NaiveDate) -> Result<(String, String, String)> {
    if preset.is_empty() {
        if from.is_empty() || to.is_empty() {
            bail!("provide a preset ({PRESETS}) or --from/--to dates");
        }
        return Ok((from.into(), to.into(), format!("{from} -> {to}")));
    }
    let day = TimeDelta::days(1);
    let monday = today - TimeDelta::days(i64::from(today.weekday().num_days_from_monday()));
    let first_of_month = today.with_day(1).expect("every month has a day 1");
    let span = |name: &str, start: NaiveDate, end: NaiveDate| (start, end, format!("{name} ({start} -> {end})"));
    let (start, end, label) = match preset {
        "today" => (today, today, format!("today ({today})")),
        "yesterday" => {
            let y = today - day;
            (y, y, format!("yesterday ({y})"))
        }
        "this-week" => span("this week", monday, today),
        "last-week" => span("last week", monday - TimeDelta::days(7), monday - day),
        "this-month" => span("this month", first_of_month, today),
        "last-month" => {
            let last = first_of_month - day;
            span("last month", last.with_day(1).expect("every month has a day 1"), last)
        }
        _ => bail!("unknown preset {preset:?} (use: {PRESETS})"),
    };
    Ok((start.to_string(), end.to_string(), label))
}

/// Seconds per project, sorted by project name.
pub fn compute_project_totals(entries: &[TimeEntry], projects: &[Project]) -> Vec<ProjectTotal> {
    let names = project_names(projects);
    let mut totals: BTreeMap<&str, i64> = BTreeMap::new();
    for (e, dur) in counted(entries) {
        *totals.entry(e.project_id.as_str()).or_default() += dur;
    }
    let mut result: Vec<ProjectTotal> = totals
        .into_iter()
        .map(|(id, duration)| ProjectTotal { name: name_of(&names, id), duration })
        .collect();
    result.sort_by(|a, b| a.name.cmp(&b.name));
    result
}

/// Seconds per project and, within each, per task; both sorted by name. A task is named
/// by its Clockify task, else the entry name, else the description, else "(no task)".
pub fn compute_task_breakdown(entries: &[TimeEntry], projects: &[Project]) -> Vec<ProjectTasks> {
    let names = project_names(projects);
    let mut by_project: BTreeMap<&str, BTreeMap<&str, i64>> = BTreeMap::new();
    for (e, dur) in counted(entries) {
        let task = [e.task.as_ref().map_or("", |t| t.name.as_str()), e.name.as_str(), e.description.as_str()]
            .into_iter()
            .find(|n| !n.is_empty())
            .unwrap_or("(no task)");
        *by_project.entry(e.project_id.as_str()).or_default().entry(task).or_default() += dur;
    }
    let mut result: Vec<ProjectTasks> = by_project
        .into_iter()
        .map(|(id, tasks)| ProjectTasks {
            name: name_of(&names, id),
            duration: tasks.values().sum(),
            tasks: tasks.into_iter().map(|(name, duration)| TaskTotal { name: name.into(), duration }).collect(),
        })
        .collect();
    result.sort_by(|a, b| a.name.cmp(&b.name));
    result
}

/// Entries that count toward totals, with their seconds: a project, a parseable start
/// and end (not a running timer), and at most 24h (longer rows are ranges, not entries).
fn counted(entries: &[TimeEntry]) -> impl Iterator<Item = (&TimeEntry, i64)> {
    entries.iter().filter(|e| !e.project_id.is_empty()).filter_map(|e| {
        let (start, end) = e.interval()?;
        let dur = (end - start).num_seconds();
        (dur != 0 && dur <= 24 * 3600).then_some((e, dur))
    })
}

fn project_names(projects: &[Project]) -> HashMap<&str, &str> {
    projects.iter().map(|p| (p.id.as_str(), p.name.as_str())).collect()
}

/// The project's name, or its id when the name is unknown or empty.
fn name_of(names: &HashMap<&str, &str>, id: &str) -> String {
    names.get(id).filter(|n| !n.is_empty()).copied().unwrap_or(id).to_string()
}
```

```rust
fn load_from(rms_env: &Path, rms_trello_env: &Path, config_path: &Path, env: impl Fn(&str) -> Option<String>) -> Config {
    let mut cfg = Config::default();

    for (key, val) in read_env_file(rms_env) {
        match key.as_str() {
            "CLOCKIFY_API_KEY" => cfg.api_key = val,
            "CLOCKIFY_WORKSPACE_ID" => cfg.workspace_id = val,
            _ => {}
        }
    }
    for (key, val) in read_env_file(rms_trello_env) {
        match key.as_str() {
            "TRELLO_API_KEY" => cfg.trello_api_key = val,
            "TRELLO_TOKEN" => cfg.trello_token = val,
            _ => {}
        }
    }

    // A missing or unparseable file is skipped, as the Go version did.
    let file = std::fs::read_to_string(config_path).ok().and_then(|s| toml::from_str::<FileConfig>(&s).ok());
    if let Some(f) = file {
        set(&mut cfg.api_key, f.api_key);
        set(&mut cfg.workspace_id, f.workspace_id);
        set(&mut cfg.default_project_id, f.default_project_id);
        set(&mut cfg.trello_api_key, f.trello_api_key);
        set(&mut cfg.trello_token, f.trello_token);
        set(&mut cfg.user_id, f.user_id);
        if let Some(p) = f.project {
            cfg.project_mappings = p;
        }
    }

    let var = |k: &str| env(k).filter(|v| !v.is_empty());
    set(&mut cfg.api_key, var("CLOCKIFY_API_KEY"));
    set(&mut cfg.workspace_id, var("CLOCKIFY_WORKSPACE_ID"));
    set(&mut cfg.default_project_id, var("CLOCKIFY_DEFAULT_PROJECT_ID"));
    set(&mut cfg.trello_api_key, var("TRELLO_API_KEY"));
    set(&mut cfg.trello_token, var("TRELLO_TOKEN"));
    cfg
}

fn set(dst: &mut String, val: Option<String>) {
    if let Some(v) = val {
        *dst = v;
    }
}

/// KEY=VALUE pairs from a .env file: blank lines and # comments skipped, both sides
/// trimmed, split at the first '='. A missing file yields nothing.
fn read_env_file(path: &Path) -> Vec<(String, String)> {
    std::fs::read_to_string(path)
        .unwrap_or_default()
        .lines()
        .map(str::trim)
        .filter(|l| !l.is_empty() && !l.starts_with('#'))
        .filter_map(|l| l.split_once('='))
        .filter(|(k, _)| !k.is_empty())
        .map(|(k, v)| (k.trim().to_string(), v.trim().to_string()))
        .collect()
}

impl Config {
    /// The Clockify project for a Trello board: a board-id match (only when the card has
    /// a board id), then a case-insensitive substring match on the name either way round,
    /// then the default project.
    pub fn get_clockify_project_id(&self, board_id: &str, board_name: &str) -> String {
        if !board_id.is_empty()
            && let Some(m) = self.project_mappings.iter().find(|m| m.trello_board_id == board_id)
        {
            return m.clockify_project_id.clone();
        }
        if board_name.is_empty() {
            return self.default_project_id.clone();
        }
        let board = board_name.to_lowercase();
        self.project_mappings
            .iter()
            .find(|m| {
                let name = m.name.to_lowercase();
                board.contains(&name) || name.contains(&board)
            })
            .map_or_else(|| self.default_project_id.clone(), |m| m.clockify_project_id.clone())
    }
}
```

```rust
/// The short id and card number from a card URL. Long URLs
/// (https://trello.com/c/QCxVCjm3/320-some-title) carry the number before the slug's
/// first dash; short ones (https://trello.com/c/QCxVCjm3) use the short id as the number.
fn extract_ids(url: &str) -> (String, String) {
    let Some((_, after)) = url.split_once("/c/") else {
        return (String::new(), String::new());
    };
    let mut path = after.split('/');
    let short_id = path.next().unwrap_or("").to_string();
```

```rust
use anyhow::{Context, Result, bail};
use chrono::{DateTime, FixedOffset, NaiveDate, NaiveTime, TimeDelta, Timelike, Utc};

use crate::clockify::Client;

/// How the log command's positional arguments set the entry's time. Times of day are
/// seconds from midnight in VNT; durations are seconds.
#[derive(Debug, PartialEq)]
enum Mode {
    /// A: ends now (or at 00:00 on an explicit --date) and lasts this long.
    Duration(i64),
    /// B: start and end times of day.
    StartEnd(i64, i64),
    /// C: start time of day and duration.
    StartDuration(i64, i64),
    /// Starts this many seconds before now, and lasts the duration.
    Relative(i64, i64),
}

impl Mode {
    /// Adds `percent` to the duration so entries don't land on exact round numbers.
    /// Mode B has no duration and stays as it is.
    fn with_extra(self, percent: i64) -> Mode {
        let add = |d: i64| d + d * percent / 100;
        match self {
            Mode::Duration(d) => Mode::Duration(add(d)),
            Mode::StartDuration(s, d) => Mode::StartDuration(s, add(d)),
            Mode::Relative(ago, d) => Mode::Relative(ago, add(d)),
            b @ Mode::StartEnd(..) => b,
        }
    }
}

#[derive(Debug, PartialEq)]
struct LogArgs {
    card_url: Option<String>,
    mode: Mode,
}

/// Reads the log command's positionals: a card URL first (only without --description),
/// then <duration>, <start> <end>, <start> <duration> or "<N> ago" <duration>.
fn parse_log_args(args: &[String], description: &str) -> Result<LogArgs> {
    if args.is_empty() && description.is_empty() {
        bail!("invalid arguments: provide a card URL or --description");
    }
    let card_url = description.is_empty().then(|| args[0].clone());
    if card_url.is_some() && args.len() < 2 {
        bail!("invalid arguments: expected <duration> or <start> <end>");
    }
    let times = if card_url.is_some() { &args[1..] } else { args };
    let mode = match times {
        [d] => Mode::Duration(duration(d)?),
        [first, second] => {
            if let Ok(ago) = timeutil::parse_relative_time(first) {
                Mode::Relative(ago, duration(second)?)
            } else if let Ok(start) = timeutil::parse_time_hhmm(first) {
                match timeutil::parse_time_hhmm(second) {
                    Ok(end) => Mode::StartEnd(start, end),
                    Err(_) => Mode::StartDuration(start, duration(second)?),
                }
            } else {
                // Go's card mode logged at 00:00 here; no-card mode already refused (fix 6).
                bail!("invalid arguments");
            }
        }
        _ => bail!("invalid arguments"),
    };
    Ok(LogArgs { card_url, mode })
}

fn duration(s: &str) -> Result<i64> {
    timeutil::parse_duration(s).context("invalid duration format")
}

/// 1 to 5, from the clock's nanoseconds.
fn random_percent() -> i64 {
    let nanos = std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap_or_default()
        .subsec_nanos();
    1 + i64::from(nanos % 5)
}

/// Vietnam time (UTC+7): the zone of every time the user types.
fn vnt() -> FixedOffset {
    FixedOffset::east_opt(7 * 3600).expect("valid offset")
}

/// Start and end of the entry. `date` is the entry's day (today unless --date was given)
/// and `now` the current time; on an explicit --date, "now" means 00:00 VNT that day.
fn entry_times(mode: &Mode, date: NaiveDate, explicit_date: bool, now: DateTime<Utc>) -> (DateTime<Utc>, DateTime<Utc>) {
    let vnt = vnt();
    let midnight = date
        .and_time(NaiveTime::MIN)
        .and_local_timezone(vnt)
        .single()
        .expect("a fixed offset maps every local time once")
        .with_timezone(&Utc);
    let at = |secs: i64| midnight + TimeDelta::seconds(secs);
    let anchor = if explicit_date { midnight } else { now };
    match *mode {
        Mode::Relative(ago, d) => {
            let start = anchor - TimeDelta::seconds(ago);
            (start, start + TimeDelta::seconds(d))
        }
        Mode::Duration(d) => {
            // Ends on `date` at the anchor's VNT clock time. With --date that is 00:00,
            // so the entry falls on the day before (a follow-up fix in the spec).
            let end = at(i64::from(anchor.with_timezone(&vnt).num_seconds_from_midnight()));
            (end - TimeDelta::seconds(d), end)
        }
        Mode::StartEnd(s, e) => {
            let (start, end) = (at(s), at(e));
            (start, if end < start { end + TimeDelta::days(1) } else { end })
        }
        Mode::StartDuration(s, d) => (at(s), at(s) + TimeDelta::seconds(d)),
    }
}

/// The id of the project's task named `task_name`, created when missing. A dry run
/// never creates it and returns None instead.
fn resolve_task(client: &Client, project_id: &str, task_name: &str, dry_run: bool) -> Result<Option<String>> {
    let tasks = client.list_tasks(project_id).context("failed to list tasks")?;
    if let Some(t) = tasks.into_iter().find(|t| t.name == task_name) {
        return Ok(Some(t.id));
    }
    if dry_run {
        return Ok(None);
    }
    let task = client.create_task(project_id, task_name).context("failed to create task")?;
    Ok(Some(task.id))
}

/// The entry's name: the card number, else the description cut to 50 characters.
fn entry_name(card_number: &str, description: &str) -> String {
    if card_number.is_empty() {
        description.chars().take(50).collect()
    } else {
        card_number.to_string()
    }
}
```

```rust
fn run_log(
    args: &[String],
    date: &str,
    dry_run: bool,
    project_id_override: &str,
    task_id: &str,
    description: &str,
) -> Result<()> {
    let parsed = parse_log_args(args, description)?;
    let mode = parsed.mode.with_extra(random_percent());

    let explicit_date = !date.is_empty();
    let date_str = if explicit_date { date.to_string() } else { Local::now().format("%Y-%m-%d").to_string() };
    let day = timeutil::parse_date(&date_str).context("invalid date format")?;

    let cfg = config::load();
    let card = match &parsed.card_url {
        Some(url) => trello::fetch_card(url, &cfg.trello_api_key, &cfg.trello_token).context("failed to fetch card info")?,
        None => trello::CardInfo { title: description.to_string(), ..Default::default() },
    };

    let now = Utc::now().with_nanosecond(0).unwrap_or_else(Utc::now);
    let (start, end) = entry_times(&mode, day, explicit_date, now);
    let duration = (end - start).num_seconds();

    let mut project_id = project_id_override.to_string();
    if project_id.is_empty() && parsed.card_url.is_some() {
        project_id = cfg.get_clockify_project_id(&card.board_id, &card.board_name);
    }
    if project_id.is_empty() && description.is_empty() {
        bail!("no project ID found (configure board-to-project mapping in config or use --project-id)");
    }
    if project_id.is_empty() {
        bail!("--project-id is required when using --description without a card URL");
    }

    let client = Client::new(&cfg.api_key, &cfg.workspace_id);

    // A task is tied to a card number, so only card entries look one up.
    let task_name = format!("#{}", card.card_number);
    let task = if !task_id.is_empty() {
        Some(task_id.to_string())
    } else if parsed.card_url.is_some() {
        resolve_task(&client, &project_id, &task_name, dry_run)?
    } else {
        None
    };

    match client.entries_between(&cfg.user_id, &date_str, &date_str) {
        Ok(entries) => {
            if let Some(c) = validator::has_overlap(start, end, &entries) {
                let (cs, ce) = c.interval().expect("has_overlap only returns entries with an interval");
                bail!(
                    "Entry overlaps with existing entry {} ({} - {})",
                    conflicting_entry_label(c),
                    cs.format("%H:%M"),
                    ce.format("%H:%M")
                );
            }
            let existing = validator::daily_total(start, &entries);
            if validator::exceeds_cap(existing, duration) {
                bail!(
                    "Total time for {date_str} would be {:.1}h (exceeds 14h limit)",
                    (existing + duration) as f64 / 3600.0
                );
            }
        }
        Err(e) => {
            eprintln!("Warning: Could not fetch existing entries for overlap check: {e:#}");
            eprintln!("Proceeding without overlap validation.");
        }
    }

    let rfc3339 = |t: DateTime<Utc>| t.to_rfc3339_opts(SecondsFormat::Secs, true);

    if dry_run {
        println!("Would create time entry:");
        if card.card_number.is_empty() {
            println!("  Card:        (no ticket)");
        } else {
            println!("  Card:        {}", card.card_number);
        }
        println!("  Description: {}", card.title);
        println!("  Start:       {}", rfc3339(start));
        println!("  End:         {}", rfc3339(end));
        println!("  Duration:    {}", timeutil::format_duration(duration));
        println!("  Project:     {project_id}");
        match &task {
            Some(id) => println!("  Task:        {id}"),
            None if parsed.card_url.is_some() => println!("  Task:        (would create {task_name})"),
            None => {}
        }
        return Ok(());
    }

    let request = TimeEntryRequest {
        project_id: project_id.clone(),
        task_id: task.unwrap_or_default(),
        name: entry_name(&card.card_number, description),
        description: card.title.clone(),
        start: rfc3339(start),
        end: rfc3339(end),
        billable: true,
    };
    let result = client.create_entry(&request).context("Clockify API error")?;

    println!("Created time entry:");
    if card.card_number.is_empty() {
        println!("  Description: {}", result.description);
    } else {
        println!("  Card:        {}", card.card_number);
    }
    println!("  Start:       {}", result.time_interval.start);
    println!("  End:         {}", result.time_interval.end);
    println!("  Duration:    {}", timeutil::format_duration(duration));
    println!("  Project:     {}", result.project_id);
    if !result.task_id.is_empty() {
        println!("  Task:        {}", result.task_id);
    }
    println!(
        "  Link:       https://app.clockify.me/workspaces/{}/time-entries/{}",
        client.workspace_id(),
        result.id
    );

    if let Err(e) = print_project_total_today(&client, &cfg, &result.project_id) {
        eprintln!("Warning: Could not fetch project total: {e:#}");
    }
    Ok(())
}

fn run_summary(preset: &str, from: &str, to: &str, by_task: bool) -> Result<()> {
    let (start, end, label) = summary::resolve_date_range(preset, from, to)?;
    let cfg = config::load();
    let client = Client::new(&cfg.api_key, &cfg.workspace_id);
    let entries = client.entries_between(&cfg.user_id, &start, &end).context("Clockify API error")?;
    let projects = client.list_projects().context("Clockify API error")?;

    println!("Summary: {label}\n");
    let mut grand_total = 0;
    if by_task {
        for p in summary::compute_task_breakdown(&entries, &projects) {
            println!("{:<35} {}", p.name, timeutil::format_duration(p.duration));
            for t in &p.tasks {
                println!("  {:<33} {}", t.name, timeutil::format_duration(t.duration));
            }
            grand_total += p.duration;
            println!();
        }
    } else {
        for p in summary::compute_project_totals(&entries, &projects) {
            println!("{:<35} {}", p.name, timeutil::format_duration(p.duration));
            grand_total += p.duration;
        }
    }
    println!("{}", "\u{2500}".repeat(40));
    println!("{:<35} {}", "Total", timeutil::format_duration(grand_total));
    Ok(())
}

/// Prints today's total for the project the new entry went to.
fn print_project_total_today(client: &Client, cfg: &Config, project_id: &str) -> Result<()> {
    let today = Local::now().format("%Y-%m-%d").to_string();
    let entries = client.entries_between(&cfg.user_id, &today, &today)?;
    let projects = client.list_projects()?;
    let totals = summary::compute_project_totals(&entries, &projects);
    let name = projects.iter().find(|p| p.id == project_id).map_or(project_id, |p| p.name.as_str());
    let total = totals.iter().find(|t| t.name == name || t.name == project_id).map_or(0, |t| t.duration);
    println!("Project total today: {name} ({})", timeutil::format_duration(total));
    Ok(())
}
```

```bash
#!/usr/bin/env bash
# Compares the Go and Rust clockify binaries on read-only commands.
# Usage: parity.sh GO_BIN RS_BIN CARD_URL PROJECT_ID
set -u
GO=$1 RS=$2 CARD=$3 PROJECT=$4
D=$(mktemp -d)

check() {
  local label=$1; shift
  "$GO" "$@" >"$D/go.out" 2>"$D/go.err"; local ge=$?
  "$RS" "$@" >"$D/rs.out" 2>"$D/rs.err"; local re=$?
  if [ "$ge" = "$re" ] && cmp -s "$D/go.out" "$D/rs.out" && cmp -s "$D/go.err" "$D/rs.err"; then
    echo "SAME  $label"
  else
    echo "DIFF  $label (exit go=$ge rs=$re)"
    diff -u "$D/go.out" "$D/rs.out"
    diff -u "$D/go.err" "$D/rs.err"
  fi
}

check "summary today"            summary today
check "summary this-week by task" summary this-week --by-task
check "summary last-month"       summary last-month
check "desc B dry-run"           log --description "parity check" --project-id "$PROJECT" 09:00 11:30 --dry-run --date 2026-10-04
check "card B dry-run"           log "$CARD" 09:00 11:30 --dry-run --date 2026-10-04
check "no args"                  log
check "bad duration"             log --description x 2x
check "unknown preset"           summary nope

echo "--- expected difference: --from/--to (fixed in Rust); compare with this-week"
"$RS" summary --from "$(date -v-mon +%Y-%m-%d)" --to "$(date +%Y-%m-%d)" | tail -1
"$RS" summary this-week | tail -1
```
